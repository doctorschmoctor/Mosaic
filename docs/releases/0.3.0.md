- **Sending no longer freezes the window.** Each send runs in a helper process while Messages takes it; messages still go out one at a time, in order. Quitting while sends are queued asks first.
- **Scrolling back is light.** Earlier messages load 100 at a time by a cursor at the oldest one shown — nothing else is re-read — and other tiles are untouched.
- **Focus layout:** the message field takes clicks again after opening a conversation or switching chips.
- **Contact photos** load as avatars appear instead of the whole address book at launch.
- **Hovering the conversation list** no longer queues a database read for every row the pointer crosses; the one you click opens first.
- **Photo-heavy threads** stay smooth: thumbnail file checks moved off the main thread.
- **Adding many photos** writes them out three at a time, and a failed one leaves no partial file.
- Earlier messages load as you scroll (no button); contact and group photos; a dot on a tile that received a message while you were in another; opening a conversation puts the cursor in its tile.
